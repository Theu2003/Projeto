## Visão Geral

Aplicativo desktop que conecta moradores com empresas de coleta seletiva. Electron + React + TypeScript no front, Node.js + Express no back, SQLite (dev) / PostgreSQL (prod), Socket.IO para tempo real, Google Maps API para geolocalização.

## Banco de Dados (Prisma + SQLite)

### Tabelas

| Tabela | Campos Principais |
|--------|-------------------|
| `users` | id, name, cpf, phone, email, passwordHash, role (resident/admin), address, latitude, longitude, points, active, createdAt |
| `companies` | id, name, cnpj, responsible, phone, email, passwordHash, address, latitude, longitude, serviceAreaRadius, materials (JSON array), approved, active, rating, createdAt |
| `collection_requests` | id, userId, companyId, status (pending/accepted/on_the_way/completed/cancelled/rescheduled), materialType, quantityKg, observations, photos (JSON), desiredDate, desiredTime, latitude, longitude, address, realWeight, completedAt, createdAt |
| `materials` | id, name, icon, category, recyclable, pointsPerKg |
| `reviews` | id, userId, companyId, requestId, rating (1-5), comment, createdAt |
| `notifications` | id, userId, companyId, type, message, read, data (JSON), createdAt |
| `addresses` | id, userId, companyId, label, street, number, neighborhood, city, state, zipCode, latitude, longitude, isDefault |

### Relacionamentos

- User 1:N CollectionRequest (solicitou)
- Company 1:N CollectionRequest (coletou)
- User 1:N Review
- Company 1:N Review
- CollectionRequest 1:1 Review
- User/Company 1:N Notification

## Backend (Express + TypeScript)

### Módulos MVC

Cada módulo segue: `controller.ts` → `service.ts` → `repository.ts` → rotas

#### Auth
- `POST /api/auth/register/resident` — Cadastro morador
- `POST /api/auth/register/company` — Cadastro empresa
- `POST /api/auth/login` — Login (retorna JWT)
- `POST /api/auth/refresh` — Renovar token

#### Users (Morador)
- `GET /api/users/me` — Perfil
- `PUT /api/users/me` — Atualizar perfil
- `GET /api/users/dashboard` — Estatísticas
- `GET /api/users/points` — Sistema de pontos

#### Companies (Empresa)
- `GET /api/companies/me` — Perfil
- `PUT /api/companies/me` — Atualizar perfil
- `GET /api/companies/dashboard` — Estatísticas
- `GET /api/companies/nearby?lat=&lng=&radius=` — Empresas próximas

#### Collection Requests (Solicitações)
- `POST /api/requests` — Criar solicitação (morador)
- `GET /api/requests` — Listar (filtrado por role)
- `GET /api/requests/:id` — Detalhes
- `PUT /api/requests/:id/accept` — Aceitar (empresa)
- `PUT /api/requests/:id/reject` — Recusar (empresa)
- `PUT /api/requests/:id/on-the-way` — A caminho (empresa)
- `PUT /api/requests/:id/complete` — Concluir (empresa)
- `PUT /api/requests/:id/cancel` — Cancelar
- `PUT /api/requests/:id/reschedule` — Reagendar

#### Reviews (Avaliações)
- `POST /api/reviews` — Criar avaliação
- `GET /api/reviews/company/:companyId` — Avaliações da empresa

#### Notifications
- `GET /api/notifications` — Listar notificações
- `PUT /api/notifications/:id/read` — Marcar como lida

#### Admin
- `GET /api/admin/users` — Listar usuários
- `GET /api/admin/companies` — Listar empresas
- `PUT /api/admin/companies/:id/approve` — Aprovar empresa
- `PUT /api/admin/users/:id/block` — Bloquear usuário
- `PUT /api/admin/companies/:id/block` — Bloquear empresa
- `GET /api/admin/stats` — Estatísticas gerais
- `GET /api/admin/reports/pdf` — Relatório PDF
- `GET /api/admin/reports/excel` — Relatório Excel

### Socket.IO Events

| Evento | Direção | Payload |
|--------|---------|---------|
| `notification:new` | Server→Client | notification object |
| `request:status_changed` | Server→Client | requestId, status |
| `request:new` | Server→Company | request summary |
| `location:update` | Company→Server | lat, lng, requestId |

### Middleware

- `auth.ts` — JWT verification + role check
- `validate.ts` — Request validation (zod)
- `errorHandler.ts` — Error normalization
- `upload.ts` — Multer para fotos

## Frontend (React + TypeScript + Tailwind)

### Tema

- Tailwind CSS com dark mode (`dark:` classes)
- Toggle claro/escuro no header
- Paleta: verde (#22C55E) como primária, neutros para fundo
- Animações: framer-motion para transições de página

### Páginas

#### Auth
- `LoginPage.tsx` — Login com email/senha, toggle morador/empresa
- `RegisterResidentPage.tsx` — Cadastro morador com autocomplete de endereço

## Google Maps Integration

- **Captura de localização**: `navigator.geolocation` + reverse geocoding
- **Autocomplete de endereço**: Google Places Autocomplete
- **Mapa de solicitações**: MarkerCluster para empresa
- **Rota**: Directions Service (empresa → cliente)
- **Distância/duração**: Distance Matrix Service
- **Mapa em tempo real**: Atualização de posição da equipe
